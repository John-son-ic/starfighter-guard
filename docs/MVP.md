# 试玩版 v0.3 — 慷慨级突袭（2026-10-17）

本文件替代此前五波护舰范围，按用户本轮授权实施。单人网页、Three.js、本地运行，无后台或账号。

## 完整流程

1. 玩家Eta-2、4架ARC-170与母舰8座自动炮塔抵御3波秃鹫：6、8、10架。波间10秒应急修复。
2. 第三波结束不胜利；慷慨级用4秒跃迁入场，最终位于狩猎者级前方约5000米，舰首朝向母舰。
3. 敌舰有粒子屏障，阻挡实体弹体和飞船；外露的护盾发生器是可选择、可攻击目标，360生命。屏障存在时舰桥不可受伤。
4. 发生器击毁后护盾消失，红色背部机库门4秒打开。3架Y翼和2架ARC护航机依次出击，间隔1.5秒。Y翼从甲板出口爬升前往敌舰，护航机主动迎击拦截机。
5. 选择护航Y翼，或亲自攻击敌舰舰桥。舰桥1800生命，Y翼260生命、飞行速度155米/秒、每7秒发射300伤害的制导鱼雷。三架全部损失仍可由玩家完成。
6. 敌舰抵达后每22秒尝试补充3架敌机，同时敌机最多10架，优先拦截轰炸机。舰桥摧毁胜利；玩家或母舰被毁失败，同帧失败优先。

## 操控与既有玩法

鼠标转向；W/S油门；Q/E滚转；Shift能量加速与蓝色双尾焰；左键/空格激光；Tab循环选择敌机/当前舰船弱点；1集火、2归队；Esc暂停。

质子鱼雷：1200米内、前向15度、无遮挡连续锁定2秒，R按下发射，18秒冷却。120伤害、有限转弯、7秒寿命。状态文字在右下角，中央仅进度环。玩家撞实体舰体立即阵亡；撞屏障反弹提示先打发生器。无友伤。

## 建模与性能边界

6种程序化资产：狩猎者级、慷慨级、Eta-2、ARC-170、秃鹫、Y翼。模型源码和GLB均在仓库；游戏使用同一工厂，动态机库门仅游戏工厂开启。慷慨级是825米参考长度的风格化近似，Y翼也是轻量游戏模型，非电影资产复刻。

活动飞机最多20架：玩家+原4僚机+3轰炸机+新增2护航机+10敌机。母舰炮塔8座。全部弹体池上限192。精确三角形舰体遮挡，护盾用椭球扫掠检测；无实时阴影/重型后处理。

本关护盾投射节点、敌机补充机制、机库出击为原创关卡设定，不作为正史装备规格。机库只做外部滑门与浅色/暗色甲板效果，不制作可飞入的内部空间；Y翼从打开后的甲板出口离舰。

## 验收边界

已用脚本驾驶实际飞行/射击通关，并单独验证Y翼实际飞行/鱼雷击毁舰桥；浏览器检查阶段、模型、界面、重开。真人护航难度、实际设备帧率仍待试玩。联机、存档检查点、主力舰对轰和完整机库内部后置。
