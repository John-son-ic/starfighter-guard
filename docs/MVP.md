# 试玩版 v0.4 — 双舰突袭（2026-10-17）

本文件替代此前五波护舰范围，按用户本轮授权实施。单人网页、Three.js、本地运行，无后台或账号。

## 完整流程

1. 玩家Eta-2、4架ARC-170与母舰8座自动炮塔抵御3波秃鹫：6、8、10架。波间10秒应急修复。
2. 第三波结束不胜利；两艘慷慨级用4秒同时跃迁入场，分别位于(-650,0,-5000)和(650,0,-5250)米，舰首朝向母舰。
3. 每艘敌舰有独立粒子屏障，阻挡实体弹体和飞船；外露的护盾发生器是可选择、可攻击目标，360生命。屏障存在时舰桥不可受伤。
4. 每击毁一艘发生器，其护盾消失，红色背部机库门4秒打开；每次派出1架Y翼和2架ARC护航机，间隔1.5秒，两批独立且不重复，共2架Y翼+4架护航机。Y翼从甲板出口爬升前往敌舰，护航机主动迎击拦截机。
5. 选择护航Y翼，或亲自攻击敌舰舰桥。每艘舰桥1800生命，Y翼320生命，全部ARC-170为120生命，玩家100生命。Y翼飞行速度155米/秒、每7秒发射600伤害的制导鱼雷。两架全部损失仍可由玩家完成。
6. 敌舰抵达后，重炮舰每22秒尝试补充1架敌机，拦截舰每22秒尝试补充3架敌机，同时敌机最多10架，优先拦截轰炸机。两艘舰桥均摧毁才胜利，单舰被毁后其炮塔及增援停止；玩家或母舰被毁失败，同帧失败优先。

## 操控与既有玩法

鼠标转向；W/S油门；Q/E滚转；Shift能量加速与蓝色双尾焰；左键激光；空格短程跃迁（最多2500米、冷却10秒、沿途障碍前180米停止、战场边界裁剪）；Tab优先选择屏幕中心附近的敌机/当前舰船弱点/炮塔；1集火、2归队、3标记威胁；Esc暂停。

质子鱼雷：1200米内、前向15度、无遮挡连续锁定2秒，R按下发射，18秒冷却。120伤害、有限转弯、7秒寿命。状态文字在右下角，中央仅进度环。玩家未开启主动护盾时撞实体舰体立即阵亡；撞屏障反弹提示先打发生器。无友伤。

## 建模与性能边界

6种程序化资产：狩猎者级、慷慨级、Eta-2、ARC-170、秃鹫、Y翼。模型源码和GLB均在仓库；游戏使用同一工厂，动态机库门仅游戏工厂开启。慷慨级是825米参考长度的风格化近似，Y翼也是轻量游戏模型，非电影资产复刻。

活动飞机最多21架：玩家+原4僚机+2轰炸机+新增4护航机+10敌机。母舰炮塔8座；每艘敌舰2门对舰炮+4门近防炮，共12门，每门150生命，护盾解除后可选中击毁。重炮舰主炮36伤害/6秒、拦截舰主炮18伤害/6秒，近防炮12伤害/2.4秒；共和国对舰炮6伤害/5秒，双方使用真实弹体命中，敌舰屏障挡住共和国炮击。全部弹体池上限192。精确三角形舰体遮挡，护盾用椭球扫掠检测；无实时阴影/重型后处理。

本关护盾投射节点、敌机补充机制、机库出击为原创关卡设定，不作为正史装备规格。机库只做外部滑门与浅色/暗色甲板效果，不制作可飞入的内部空间；Y翼从打开后的甲板出口离舰。

## 验收边界

已用脚本驾驶实际飞行/射击通关，并单独验证Y翼实际飞行/鱼雷击毁舰桥；浏览器检查阶段、模型、界面、重开。真人护航难度、实际设备帧率仍待试玩。联机、存档检查点和完整机库内部后置。

Tab选敌：按实际摄像机投影，优先选屏幕内最靠近中心的有效目标；没有屏内目标时选视线夹角最小的目标。重复按下保持中心目标，转动视角后再按可换目标。仅选择目标，鱼雷仍需瞄准并持续锁定2秒。

A/D：按住向左/右转向，按键期间优先于鼠标水平转向，两键同时按下水平转向归零；松开后恢复鼠标控制。鼠标俯仰及Q/E滚转保持可用。

质子鱼雷现有两枚独立弹位，每枚发射后单独冷却18秒；另一枚就绪时可重新锁定2秒并按R发射。右下角分别显示1号/2号状态，两枚都冷却时显示最近一枚恢复的倒计时。暂停冻结两路冷却，重开恢复两枚。

主动护盾：按F开启5秒，期间敌方激光（含舰炮能量弹）不扣玩家生命，撞母舰或敌舰实体会安全弹开；不穿透敌舰屏障。冷却从开启时起30秒，长按不会自动重开。左下角显示持续/冷却/就绪，战机周围有淡蓝色薄膜。暂停冻结计时，重开清空冷却。

## C25 / 战术与反馈优化

两舰角色为原创关卡分工：重炮舰主炮更强，拦截舰增援更多；同样保留2门主炮与4门近防炮。单舰被毁后对应增援与炮火停止，使攻击次序影响剩余战况。

重型主炮使用加粗菱形目标框，近防炮使用圆框；选中时右侧提示拆除用途。实际激光击中Y翼或敌方重炮损伤母舰时，右侧显示5秒警报，Y翼优先，屏外Y翼也显示方向标记；声音最多每6秒一次。3或警报按钮选择仍存活的攻击者；攻击者为受屏障保护的炮塔时改选对应发生器。警报不自动转向、不提供鱼雷自动锁定。

Y翼重型鱼雷由300提高至600伤害，仍需实际飞抵、瞄准并命中；1800生命舰桥单靠Y翼需命中3枚。玩家鱼雷仍为120伤害。炮塔摧毁留下残骸，舰桥低于65%生命出现火焰与烟；破盾有扩散环，敌舰被毁后4秒渐增火点、倾斜下沉并淡出。毁灭效果期间该舰立即停止战斗与碰撞，最终胜负规则不等待演出。特效最多12组火焰/烟及12块炮位残骸，无新纹理或后处理依赖。
