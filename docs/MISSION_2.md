# 任务2：断链行动

这是克隆人战争背景的原创关卡，不作为正史设施规格。任务1继续保留。

## 启动与操控

双击根目录start-play.cmd，已有页面Ctrl+F5刷新。在简报页“选择任务”中选择“02 · 断链行动 / 突袭”后进入战场。也可访问http://127.0.0.1:5174/?mission=relay。

Esc暂停；暂停或结算页“选择其他任务”返回选择，切换或从头开始会清除本次进度。鼠标/A/D转向、W/S油门、左键激光、Tab选择视野中心目标、R锁定鱼雷、F五秒主动护盾、空格短程跃迁等操作沿用第一关。1/2仍为僚机集火敌机/归队。

## 路线与决策

1. 玩家Eta-2带两架ARC-170清理4架巡逻秃鹫，穿过稀疏小行星区域；清空巡逻且抵近空间站1800米内后进入设施阶段。小行星留有宽阔的中央通道，仍有实体碰撞。
2. 两设施各600生命，任选攻击顺序。通讯阵列存活时每24秒尝试补2架敌机，场上最多8架；摧毁后停止后续增援。火控中心控制6门近防炮，摧毁后全站防御炮停止；近防炮本身各150生命，也可先逐门摧毁。
3. 两设施都毁后，中央两片装甲门用2秒打开，1200生命的反应堆成为目标。从上方抵近射击，跟随目标框及金色提前量，不需要进入空间站内部。激光与质子鱼雷均有效，未解锁前不能提前损伤反应堆。
4. 反应堆毁后立即开始60秒撤离，残余敌机追击；不足4架时补至4架，不再持续增援。蓝色圆环和屏外箭头指向撤离点。空间站继续发生局部爆炸，玩家全程可操控。
5. 撤离第8秒守望号开始跃迁，4秒后入场完成，8座炮塔以真实弹体压制追兵。随后有6秒掩护期，第18秒撤离区正式生效。进入撤离点240米内且存活即完成，不需要清空所有追兵。提前到达可以在附近机动等待，不必飞入母舰。
6. 座机被毁或第60秒仍未完成撤离则失败，同帧失败优先。母舰是收尾救援力量，本关无需再次承担守护母舰目标。

## 检查点

抵达设施阶段、反应堆刚暴露时各记录一次，后者覆盖前者。失败页显示当前可重试阶段；重试保留记录时的座机/僚机损伤、僚机损失、飞行与武器/冷却状态、当时存活敌机和设施损伤，清除残弹，不补满生命。救援/撤离失败会回到反应堆暴露时重新攻击。

仅本次任务有效，刷新或关页不保存。两架僚机全部损失不会强制失败；仍可由玩家独立完成。

## 数值与实现边界

空间站为900米级原创近似模型：通讯碟、火控方塔、环形设备带与可开合反应堆装甲门。静态GLB4676三角面、8材质网格、343600字节，源文件src/visual/models/relay.ts，模型页可查看并导出。游戏中的门保留为动态对象；不制作可飞入的内部空间。两架僚机各120生命，玩家100；近防炮每2.5秒10伤害，救援舰炮每0.9秒36伤害，均需实际命中。活动敌机最多8架。

目标体验约5—7分钟，最终时长和难度由真人试玩校准。已通过实际输入脚本完整通关和浏览器验证；软件渲染不能证明目标硬件帧率。
