# 试玩说明（首版原型）

2026-10-16更新：现在是5波共46架敌机、4架僚机、母舰8座自动炮塔支援。波间10秒有限修复玩家、存活僚机和母舰，不会复活已毁友机。炮塔自动开火，保持友军免伤。

本文对应 `src/app/game/` 当前实现的实际行为。数值取自代码（world.ts / start.ts / shared/config.ts），不是设计目标。

## 1. 启动

1. 双击仓库根目录的 `start-dev.cmd`。第一次运行会自动执行 `npm ci`（需要网络），之后每次直接启动。
2. 命令窗口出现地址（`http://127.0.0.1:5173/`）后浏览器会自动打开。也可手动执行 `npm run dev` 再自行访问该地址。
3. 看到标题为“余烬航道”的任务简报页即启动成功。
4. 点击 **进入战场** 开始；开始后简报页收起。
5. 想只看舰船模型，点简报页或左上角标题的 **查看舰船模型**，或直接访问 `/?mode=models`；从模型页返回用页面上的链接或改回根地址。
6. 关闭命令窗口即停止服务。

如果页面只在中央显示一行“场景无法启动…”，说明浏览器没有可用的 WebGL 2 或硬件加速；换用支持 WebGL 2 的桌面浏览器，或开启硬件加速后重试。

### 另一种启动方式：已经拿到构建文件的离线包

如果你拿到的是一份**已经构建好的目录**（里面有 `dist/`、`scripts/serve-release.mjs`、`start-play.cmd` 和一份 README），那么不需要 `npm install`，也不需要联网：

1. 确认已安装 Node.js 24 LTS。
2. 双击该目录里的 `start-play.cmd`（不是仓库根目录的 `start-dev.cmd`）。
3. 按窗口提示打开 `http://127.0.0.1:5174/`。
4. 端口被占用时执行 `node scripts/serve-release.mjs --port 5175`。

详见包内 `README.md` 或 [docs/OFFLINE_RELEASE.md](OFFLINE_RELEASE.md)。开发时用 `start-dev.cmd`，已构建的试玩副本用 `start-play.cmd`。

## 2. 操控

| 操作 | 键位 | 实际效果 |
| --- | --- | --- |
| 转向 | 移动鼠标 | 光标离画面中心越远，转向越快；偏离中心不足约 3% 的范围内不转向 |
| 停止转向 | 鼠标移回中心 | 保持当前朝向，不再改变 |
| 油门 | W / S | W 加速、S 减速。速度限制在 55—190 m/s，加/减速约 65 m/s² |
| 滚转 | Q / E | Q 向左滚、E 向右滚，约 1.4 弧度/秒 |
| 加速 | Shift | 按住期间实际速度 ×1.6，同时加速能量以 30/秒 消耗；松开或不按则以 18/秒 回复 |
| 开火 | 鼠标左键（或空格） | 发射激光炮，约 0.15 秒一发 |
| 选择目标 | Tab | 在所有存活敌机中按距离轮换锁定 |
| 集火 | 1 | 四架僚机攻击当前锁定目标 |
| 归队 | 2 | 四架僚机返回你两侧的编队位置 |
| 暂停 / 继续 | Esc 或右上角“暂停”按钮 | 打开暂停页；暂停期间战场不推进 |
| 重新开始 | 暂停页或结算页的“重新开始” | **立即重置并开始一局新任务**（不会停在简报页）；首波仍然延迟 3 秒出现 |

**重开的实际行为**：点“重新开始”会重建战场、清空击毁计数与目标锁定、恢复满机体与满母舰完整度，并直接进入可操控状态。第一波敌机不是立刻出现，而是按正常节奏在 3 秒后到达。

**输入在暂停时会被清空**：进入暂停（Esc、按钮、失去焦点或切换标签页）会清掉当前按键、开火状态和鼠标转向；恢复、重开同样清零。暂停期间移动鼠标不会积累转向，恢复后不会突然甩头。

转向速率上限：偏航约 1.15 弧度/秒、俯仰约 1.0 弧度/秒、滚转约 1.4 弧度/秒。灵敏度设置会放大鼠标输入（见第 7 节），但不会超过这个上限。

窗口失去焦点、或切到其他标签页时会自动暂停。回到页面后需要自己按 Esc 或点“继续飞行”恢复。

## 3. 界面

- **准星**：画面中央的圆环，代表机头方向。当机头已经对准提前量点、且武器没有过热时，准星会变亮（“可射击”状态）。
- **转向指示点**：准星旁边的金色小圆点，显示当前鼠标输入带来的转向量；鼠标在中心死区时它停在中间。
- **提前量提示**：锁定目标后出现的金色圆环，指示**匀速截击解**算出的碰撞点——即激光按 720 m/s 飞行、目标保持当前航向与速度时两者相遇的位置。若该假设下无解，圆环与虚线会隐藏并提示“暂无有效截击点 · 接近目标”。
- **提前量虚线**：锁定目标且两者同时可见时，一条金色虚线把敌机机身与提前量圆环连起来，帮助判断需要提前多少。
- **屏外方向箭头**：敌机与母舰飞出画面时，标记会停在画面边缘，分别变为橙色和青色方向三角。锁定敌机在屏外且仍有有效截击点时，右下角提示“目标在视野外 · 按箭头转向”。僚机飞出画面时标记隐藏。
- **舰体遮挡提示**：锁定目标被母舰舰体挡住时，提前量圆环与虚线会隐藏，右下角提示“舰体遮挡 · 请改变攻击角度”，锁定标记变为虚线框。这是提示你换个角度，不是故障。
- **目标读数**：画面右下方、底部仪表上方显示当前锁定目标的名称与距离；被遮挡时会出现遮挡提示；未锁定时显示“暂无目标”，按 Tab 选择。
- **舰船标记**：画面中可见的友机与敌机都有标记，带机型名与距离。敌机偏暖色，友机与母舰偏青色；母舰标记是一个小圆环（不带方框）。**锁定目标的标记会显示一条血条**，其他目标不显示血条；未锁定的距离按 10 米取整显示。
- **母舰面板**：右上显示“守望号”完整度百分比（母舰 4000 点生命，面板显示值 = 生命 ÷ 40）。
- **机体 / 武器热量 / 加速能量**：底部三条。热量接近满时不要持续按住扳机。
- **敌机击毁计数**：底部显示 `已击毁 / 46`，包括僚机和母舰击毁的敌机。
- **波次**：顶部显示 `WAVE n / 3`；波间显示“下一波 n 秒”。
- **僚机面板**：左侧显示四架 ARC-170 的机体百分比或“失联”，以及当前执行的是集火、归队还是自动护航。
- **状态提示**：画面中下方显示“敌机第 n 波！”“舰体碰撞！”等一次性提示。
- **命中反馈**：你的激光命中敌机时准星处出现 × 并淡出。友机不会被你的激光命中（见第 6 节），所以也不会出现 ×。自己被击中或撞舰时画面边缘泛红。
- **音效范围**：目前只有开火、爆炸、**自己被击中**，以及按下 1/2 下达指令时有音效。**击中敌机与撞舰都没有独立音效**——击中敌机只有 × 的视觉反馈，撞舰只有泛红与文字提示。
- **帧率读数**：简报与暂停页的设置区下方显示“最近帧率 … fps · P95 … ms”，每约 1 秒刷新，只统计实际游玩期间的帧间隔。移动窗口本身造成的卡顿也会被计入。

### 提前量提示能信到什么程度

游戏现在用**精确的匀速截击解**计算提前量（从实际炮口位置、按弹速 720 m/s 与 2 秒弹体寿命求解），HUD 上显示的就是射击辅助实际使用的那个点。但它仍然只是一个**匀速直线预测**：

- 它按目标**当前**航向与速度外推；目标随后转弯、变速或规避时，预测点会偏，需要跟着标记继续修正。
- 机头大致对准提前量点（约 4° 以内）时开火，激光会自动沿该方向射出（从炮口出发，不继承你的速度）；偏离太多时激光沿机头方向飞，通常打空。
- **没有“一次命中必击毁”的保证**：是否击毁取决于目标剩余机体与累计命中伤害，当前没有分部位伤害。
- 准星变亮只代表“机头已对准截击方向且武器未过热”，不代表这一发一定命中。

**找不到提前量时**：目标距离过远、预测截击时间超过弹体两秒寿命时，提前量圆环与虚线会隐藏，右下角提示“暂无有效截击点 · 接近目标”。缩短距离或换目标后再瞄准。

## 4. 金色标记区域（母舰弱点）

母舰外侧有一处带金色圆环信标的受损区域。部分敌机会专门飞向它并开火；命中该区域 105 米范围内的敌方炮弹，对母舰造成 **1.2 倍**伤害。你的激光不会伤害母舰，但仍会被舰体挡住。看到敌机开始朝信标俯冲时优先拦截它们。

## 5. 胜负条件

- **胜利**：清除五波共 46 架敌机，且你的座机与母舰都存活，结算显示“空域已肃清”。
- **失败**：座机被击毁，或母舰被击毁。结算页会分别给出“座机已被摧毁”或“守望号失去作战能力”的提示。
- 同一帧内同时发生“清空最后一波”和“座机/母舰被毁”时，判定为失败。
- 波次节奏：简报 3 秒后第一波（6 架）出现；每清空一波后间隔 10 秒出现下一波，后四波各10架。同时最多10架敌机。

## 6. 其他实际规则

- **碰撞**：撞上母舰舰体会反弹并被扣 24 点机体（约 1 秒内不会重复扣血），不会穿舰。撞击时画面边缘泛红并提示“舰体碰撞！”，但没有碰撞音效。AI 战机会提前抬高躲避舰体，撞舰同样会被扣 10 点。
- **没有友军伤害**：你的激光**不会**打中四架 ARC-170 僚机——弹体会直接穿过友机，友机既不掉血也不会出现命中反馈。反过来，僚机的激光也不会打中你。敌方炮弹则会被舰体和战机正常拦截。
- **机体与生命**：座机100点机体，僚机各180点，母舰4000点；界面显示百分比。僚机被击毁后显示“失联”且不会重生。
- **敌方火力**：秃鹫战机对空伤害 5 点/发，约 0.75 秒一发；对母舰弱点区域为 6 点/发。
- **作战边界**：离原点约 2350 米处会出现“接近作战边界，飞行辅助正在引导返航”的提示，并自动把机头转向战场中心。这是软性引导，不是硬墙。
- **僚机**：默认自动攻击最近的敌机；按1让四架僚机集中攻击锁定目标，按2召回掩护。集火目标被击毁后自动回到自动护航。
- **过热**：连续开火约 11 发后武器过热，面板显示“过热”，此时无法射击；热量降到约 35% 以下才会解除。

## 7. 设置

简报页与暂停页的设置区可以调整：

- **音量**：0—1，控制音效音量。
- **灵敏度**：0.2—3，放大鼠标转向输入。
- **画质**：标准 / 低。低画质把内部像素比降到 0.75（标准档最高 1.5），也就是减少渲染像素量。它能减轻显卡负担，但**不承诺帧率一定提高某个固定数值**——提升多少取决于你的机器与瓶颈在哪。

三项都在**改变时立即保存**到浏览器本地存储（键 `starfighter-guard:settings:v1`），下次打开自动恢复。如果浏览器禁用了本地存储，游戏仍可运行，但设置不会被记住。

## 8. 当前仍是原型

这是一个可试玩的原型，不是完成的游戏：

- 场景只有星空、一个方向光、母舰、7 架战机与简化特效；没有人物、座舱、机库、过场或音乐。
- 操控手感、难度、提示时机都还会根据试玩反馈调整。
- 首版目标时长是 5—8 分钟，这是体验目标，尚未在目标硬件上完成验收。
- 帧率读数只反映你这台机器的实际表现；软件渲染或不支持硬件加速的环境下会很慢。

反馈时最有用的信息是：你在做什么操作、看到了什么、以及当时面板上的帧率与 P95 数值。
