# 试玩说明 — 双舰突袭

2026-10-17。开始页可选“01 · 余烬航道”或“02 · 断链行动”。暂停或结算页可返回任务选择；切换任务会清除当前进度。本文的三波护舰路线为任务1，第二关详见[MISSION_2.md](MISSION_2.md)。

## 启动

已安装Node.js 24且目录中有dist时，双击根目录start-play.cmd，打开http://127.0.0.1:5174/。更新后按Ctrl+F5刷新；关闭服务命令窗口即停止。

开发使用start-dev.cmd（第一次npm ci需要网络），地址http://127.0.0.1:5173/。模型页为/?mode=models，提供7种模型与GLB导出。离线包说明见[OFFLINE_RELEASE.md](OFFLINE_RELEASE.md)。

## 操作

| 操作 | 按键 |
| --- | --- |
| 转向 | 鼠标偏离中心；移回中心保持航向 |
| 调节速度 | W / S，55—190米/秒 |
| 加速 | Shift，消耗能量，双引擎出现蓝色尾焰 |
| 滚转 | Q / E |
| 激光炮 | 左键，持续射击会过热 |
| 短程跃迁 | 空格，沿机头最多2500米，冷却10秒；遇到舰体/屏障提前停止 |
| 选择敌机或舰船弱点 | Tab |
| 质子鱼雷 | 锁定完成后按R |
| 集火 / 归队 | 1 / 2 |
| 标记当前警报威胁 | 3，或点击右侧警报按钮 |
| 暂停 | Esc；失焦也自动暂停 |

鱼雷需要目标位于机头前方15度、1200米内且无遮挡，持续瞄准2秒。右下角金色百分比表示锁定中，绿色“R发射鱼雷”表示可以发射，蓝色倒计时表示18秒冷却。提前长按R不会在锁定后自动发射，需要松开再按。冷却、目标切换或失去射界会清空进度；发射后自主追踪原目标。激光金色提前量环与鱼雷锁定进度环用途不同。

## 任务路线

1. 消灭3波敌机（6、8、10架），保护守望号。波间修复玩家25、存活僚机35和母舰180生命，不复活友机。
2. 两艘慷慨级在前方约5000米处同时跃迁出现。跟随“重炮舰 / 拦截舰 护盾发生器”飞过去；必要时Tab切回弱点。战区已扩大，能够飞抵敌舰。
3. 攻击屏障外、桅杆顶部的发生器。屏障会阻挡弹体，舰桥此时不可伤害。发生器生命360，可用激光或鱼雷攻击。
4. 每击毁一艘发生器，该舰屏障消失，守望号派出1架金色中队Y翼和2架ARC-170护航机。两次共2架Y翼、4架护航机；左侧显示Y翼生命及待出击状态。重炮舰每22秒补充最多1架拦截机，拦截舰最多3架，同时敌机总数最多10架。
5. 护航Y翼飞到敌舰附近，让它们发射重型鱼雷；也可以直接攻击标记的舰桥。Y翼全部损失不会直接失败，玩家仍可攻击各舰1800生命的舰桥。Y翼生命由260提升到320；原有和新增ARC-170生命均由180降至120，玩家仍为100。Y翼优先攻击对应敌舰，击毁后转向其他已解除护盾的敌舰。
6. 两艘舰桥均被毁后才胜利。单舰被毁后，其炮塔和增援随之停止。玩家或守望号被毁则失败，点击重新开始重置全关。

## 碰撞与伤害

玩家未开启主动护盾时撞上母舰或敌舰实体立即阵亡。护盾屏障会将飞船反弹，提示先摧毁发生器。友军免伤；普通命中有准星×/血条反馈，爆炸与鱼雷发射有声音。鱼雷直接命中造成120伤害，无范围伤害；Y翼重型鱼雷每枚600，单靠它命中3枚可摧毁满血舰桥；玩家鱼雷仍是120。

机库为外部动画，不可飞入内部。可用低画质减少渲染负担。帧率文字来自本机测量，脚本通关与软件渲染截图不代表真人难度或真实GPU性能验收。

## 敌舰防御与对轰

每艘慷慨级有2门对舰主炮和4门近防炮，每门150生命。护盾解除后，Tab可以选择炮塔，激光与鱼雷可将其击毁并永久停止其火力。护盾存在时先攻击外露发生器。双方主炮从敌舰抵达起互相射击；共和国炮火在护盾解除后协助损伤舰桥，敌舰主炮持续威胁母舰。可优先拆除主炮减轻母舰压力，或清理近防炮保护Y翼。

Tab选敌：按实际摄像机投影，优先选屏幕内最靠近中心的有效目标；没有屏内目标时选视线夹角最小的目标。重复按下保持中心目标，转动视角后再按可换目标。仅选择目标，鱼雷仍需瞄准并持续锁定2秒。

A/D：按住向左/右转向，按键期间优先于鼠标水平转向，两键同时按下水平转向归零；松开后恢复鼠标控制。鼠标俯仰及Q/E滚转保持可用。

质子鱼雷现有两枚独立弹位，每枚发射后单独冷却18秒；另一枚就绪时可重新锁定2秒并按R发射。右下角分别显示1号/2号状态，两枚都冷却时显示最近一枚恢复的倒计时。暂停冻结两路冷却，重开恢复两枚。

主动护盾：按F开启5秒，期间敌方激光（含舰炮能量弹）不扣玩家生命，撞母舰或敌舰实体会安全弹开；不穿透敌舰屏障。冷却从开启时起30秒，长按不会自动重开。左下角显示持续/冷却/就绪，战机周围有淡蓝色薄膜。暂停冻结计时，重开清空冷却。

## 战术警报与攻击顺序

重炮舰的主炮威胁更大，拦截舰则放出更多敌机。母舰血量吃紧时优先破重炮舰护盾、拆主炮；护航压力大时可先击毁拦截舰，切断更多敌机增援。两舰仍需全部摧毁才能获胜。

主炮目标框为加粗菱形，近防炮为圆形；选中时右侧说明该目标的作用。Y翼中弹或母舰遭敌方重炮命中后，右侧出现短暂警报，Y翼标记高亮，屏外显示方向。按3选择一个仍存在的威胁；受屏障保护的炮塔会改选其发生器。它只选择目标，仍需自行飞行、瞄准和锁定。警报持续5秒，提示音间隔至少6秒。

炮塔被毁会留下黑色残骸；舰桥重伤出现火焰与烟，敌舰被毁后4秒倾斜下沉并淡出。这段演出期间该舰已经停止射击和增援。Y翼到位后的3次重型鱼雷命中能完成一舰轰炸，清理近防炮和追击它的秃鹫更有价值。

## 阶段检查点与反馈

第三波结束、两艘敌舰开始跃迁时，自动记录一次本次任务的检查点。之后玩家或母舰被毁，失败页可选“从敌舰来袭重试”；“从头开始”仍会重打三波。

重试保留记录时的母舰/座机损伤、存活僚机及其生命、座机位置航向/速度、武器热量、加速能量和鱼雷/跃迁/主动护盾冷却；不会复活已损失的僚机或补满生命。两艘敌舰及其护盾、炮塔、支援出击进度回到跃迁起点，战场残余弹体清除。可以重复重试同一个检查点。检查点仅在当前任务内存中有效，刷新页面、关闭页面或从头开始都会清除，不是跨次游玩的存档。前三波中失败仍需从头开始。

玩家鱼雷发射是下滑推进声，有效命中是低频冲击声；玩家击毁敌机/炮塔/弱点有双音确认。打中敌舰屏障或普通舰体仍只有相应撞击/爆炸反馈，不会冒充有效弱点命中。F护盾挡激光时，从实际命中方向扩散蓝色涟漪并响短促提示音；护盾撞舰弹开有约0.28秒、幅度小于1度的镜头震动。暂停冻结视觉反馈，恢复继续，重开清空；音量设置为0可静音。
