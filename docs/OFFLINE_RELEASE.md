# 离线试玩包说明

这个目录是一份**已经构建好的**试玩副本，不包含 `node_modules`，也不需要联网。把它整体复制到任何位置都能运行。

## 前提

- 已安装 Node.js 24 LTS，以及支持 WebGL 2 的桌面浏览器。
- **运行游戏不需要 npm、不需要联网。** 只有从源码开发、首次安装依赖时才需要网络。

## 启动

1. 确认 `dist/index.html` 与本文件、`start-play.cmd`、`scripts/serve-release.mjs` 在同一个目录下。
2. 双击 `start-play.cmd`。
3. 命令窗口会打印地址，例如：

   ```text
   游戏已就绪：http://127.0.0.1:5174/
   舰船模型页：http://127.0.0.1:5174/?mode=models
   ```

4. 在浏览器里打开该地址（可复制粘贴）。服务只监听本机 `127.0.0.1`，局域网内其他设备访问不到。
5. **关闭命令窗口即停止服务。** 窗口保留全部日志，如果启动失败，把窗口里的完整内容反馈给开发方即可。

也可以不用批处理，直接在包目录执行：

```text
node scripts/serve-release.mjs
```

## 端口被占用

默认端口是 `5174`。如果提示端口被占用，换一个端口启动：

```text
node scripts/serve-release.mjs --port 5175
```

本工具**不会结束其他进程**。端口号范围是 1..65535。

## 常见提示

| 提示 | 含义与处理 |
| --- | --- |
| `未找到构建产物 …/dist/index.html` | 这个包里缺少构建结果。请向开发方索取完整包，或在开发副本里先 `npm run build` 再重新打包。 |
| `端口 5174 已被占用` | 按上面的 `--port` 换端口。 |
| `未找到 Node.js` | 先安装 Node.js 24 LTS，然后重新双击 `start-play.cmd`。 |
| 浏览器显示“场景无法启动…” | 浏览器缺少可用的 WebGL 2 或硬件加速；换用支持 WebGL 2 的桌面浏览器。 |

## 这不是什么

- 不是安装程序，不会写入系统目录、注册表或开机启动项。
- 启动工具只把本机已构建的静态文件提供给浏览器，没有账号、存档上传或外部网络请求。
- 不含源码、不含 `node_modules`、不含开发工具与历史截图。

## 更新内容

包是构建结果的快照。开发副本里重新 `npm run build` 之后，需要重新打包才能得到包含新内容的离线包。

## 已知限制

- 只在一台机器上用本机浏览器验证过；未做断网环境、其他浏览器或长期运行的适配验收。
- 画面表现、飞行手感与真实 GPU 帧率由开发方另行验收，本工具不对此作任何结论。
