# C16 — 慷慨级突袭任务

2026-10-17。按用户要求将防守缩短为三波，并加入敌舰、屏障、发生器、开门出击和护航/直接攻击两条路线。取代旧C07五波玩法范围；C08—C15的模型、鱼雷UI、撞舰阵亡及尾焰保留。

## 已实现

- 三波6/8/10，清完进入4秒跃迁，慷慨级最终在狩猎者级前方5000米、舰首相向。扩大飞行边界，防止原返航辅助阻止前往敌舰。
- 程序化慷慨级：骨架侧翼、双反应堆、舰桥、炮管与外露护盾桅杆。4204三角面/8材质批次/309364字节GLB。
- 程序化Y翼：896三角面/6材质批次/69536字节GLB。六模型均可在档案页查看、导出；侧栏可滚动。
- 半透明波纹粒子屏障，椭球连续碰撞挡弹体/飞船。外露发生器360生命，屏障存在时舰桥不参与可伤害目标。
- 发生器摧毁后红色机库双门4秒滑开，3架Y翼和2架ARC依次出击。Y翼260生命，以155米/秒飞向敌舰，每7秒发射300伤害实体制导鱼雷；新增护航机跟随轰炸编队/迎击敌机。
- 敌舰抵达后每22秒补充至多3架秃鹫，同时敌机最多10。新增敌机优先攻击Y翼；Y翼全灭时改攻击其他共和国战机。
- 舰桥1800生命，可由玩家激光/鱼雷或Y翼摧毁。Y翼全灭不判负。玩家或守望号被毁优先失败。敌舰摧毁触发大爆炸与胜利界面。
- HUD自动标记当前发生器/舰桥，可用Tab循环选择；显示阶段、弱点完整度、Y翼数量及三架轰炸机生命。鱼雷状态仍在右下角。

## 结构与取舍

D01纯mission模块仍负责防守波次，不改其独立胜负契约；FlightWorld拦截三波完成并接管后续stage。新阶段依然使用原固定步长、伤害、弹体池、精确三角形遮挡与重开逻辑。敌舰有精确舰体碰撞，玩家撞实体舰体立即阵亡；撞护盾反弹。

活动飞机上限20，弹体池192。世界/场景共享敌舰模型，避免渲染与碰撞不同源。动态红门由工厂可选拆分，保留原烘焙颜色；浅甲板出口上方出击，没有可飞入的机库内部。没有新增敌舰主炮对轰、存档检查点或联机。

建模参考：慷慨级采用825米长度、骨架式外观和双反应堆的资料基础：[Wookieepedia Munificent-class](https://starwars.fandom.com/wiki/Munificent-class_star_frigate)。护盾外露节点、补机节奏和发射流程是原创关卡设计，非正史参数或电影级复刻。Y翼为风格化游戏模型。
