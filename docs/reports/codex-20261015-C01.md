# C01 — 四种程序化低模与交互预览

日期：2026-10-15，Asia/Shanghai。起始commit：b7da457。负责人：Codex。

## 交付

src/visual/models/下新增四种独立工厂、低模几何辅助器、模型目录。长度统一为米，原点居中、Y向上、机头-Z、根缩放1。按材质合并几何，每个模型6—7个渲染批次。每次工厂调用拥有独立资源，disposeModel清理，避免销毁一架飞机影响其他飞机。

public/models/下提供四个GLB与manifest；源文件与导出文件同时保留。导出使用scripts/export-models.mjs，可重新生成并经GLTFLoader回读核对长度。

src/visual/viewer.ts与src/app/style.css建立档案式模型预览：切换、轨道拖动、缩放、俯视/正面/尾部、线框、自动旋转、同尺度编队及近景、浏览器导出GLB。现有start-dev.cmd直接进入该页。

## 视觉判断与限制

四种机型能够以轮廓和配色区分，结构适合当前低模首版。仍有方块化舰桥、概括化座舱/散热翼、缺少细表面结构等不足；保留为后续必要时的迭代，不在C01追求电影级模型。

同尺度近景展示母舰与三架战机的巨大尺寸差异。战斗时需要目标标识和适当相机，不能仅凭模型预览推断敌机易瞄准。

生产构建当前主JS约639KB（gzip约165KB），Vite发出大于500KB的体积提示；这是模型工具页包含Three.js和导出工具的结果，未做游戏加载/帧率基准。C02/C03如需优化，可拆分导出工具、按需加载预览，不通过调高阈值隐藏提示。

未实现/未验收：飞行、战机AI、实体碰撞/避障、伤害集成、完整关卡、硬件GPU性能。DSH代码尚未逐项审查，仍由其队列保持REVIEW。
