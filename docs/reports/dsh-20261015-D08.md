**两处据实修正**（编写时先写了、核对代码后改掉，避免把预期当成事实）：

1. 原稿写“被击中时画面边缘泛红；有受击音效”，并把碰撞也说成有音效。核对后：`hitFlash` 只在**自己被击中**和**撞舰**时置 1（`world.ts` 第 235、268 行），所以撞舰也会泛红；而 `audio.cue` 只在 `shot` / `explosion` / `player-hit` 与 1·2 指令时触发，**碰撞与命中敌机都没有独立音效**。文档与检查表均已按此改写，并在检查表 E8 明确“按现状记录，不要判定为故障”。
2. 原稿把“命中敌机时出现 ×”写成通用命中反馈。核对后：`hitConfirm` 仅在 `bolt.owner === 'player'` 时置 1（第 267 行），因此**命中僚机不会出现 ×**。已写明该条件，并在检查表加了对应验证项（E5）。

`docs/PLAYER_GUIDE.md`：启动方式（含 WebGL 2 失败提示的含义）→ 操控表（键位与**实际数值**）→ 界面各元素含义 → 金色标记区域（弱点）→ 胜负条件 → 其他实际规则（碰撞、边界、僚机、过热）→ 设置与保存 → “当前仍是原型”声明。全部为陈述句，不含未验证的通过结论。
