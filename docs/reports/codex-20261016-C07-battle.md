# C07 / 撞舰镜头与战斗扩充 / 2026-10-16

用户实机反馈帧率没有问题，但撞母舰后黑屏且无法操作；原流程太短，希望增加敌友和母舰火炮。本轮按该反馈实施，覆盖旧首版三波/7机/静态炮塔范围。

## 撞舰路径修正

检查发现原镜头在背后被舰体遮挡时，允许将追尾距离压到约1—3米，可能进入玩家机体内部；反弹后机体换向，但插值起点及平滑镜头还处于原路径，可能继续穿越舰体。已修正：

- 从碰撞前位置向接触面外退让，碰撞后同步previous，丢弃穿过舰体的插值段。
- 碰撞时记录法线和版本，相机当帧切换到安全位置，再恢复平滑跟随。
- 相机不再通过无限缩短距离挤进机体，优先保持追尾；空间不足时改用朝外/上方/侧方安全位置。
- 避障后的真实平滑镜头同样检查舰体遮挡与最小距离。

Node测试覆盖甲板、舰桥、侧舷和腹面实际碰撞，确认真实碰撞发生、相机与玩家距离大于9米、两者间无舰体遮挡、继续给转向输入后位置/姿态改变且数值有限。浏览器实际撞击后76生命，继续鼠标转向与移动有效，截图正常、异常0。用户原故障没有提供堆栈，当前修复与回归针对查到的镜头陷入路径；其他驱动或WebGL故障没有据此宣称已排除。

## 战斗扩充

- 玩家+4架ARC-170；敌机同时最多10架，共15架活动战机。
- 五波6/10/10/10/10共46架；首波3秒，波间10秒。敌方出生位置分两列，攻击战机的敌人分散选择共和国飞机，不再全部围攻玩家。
- 母舰4000生命、敌机90、僚机180。波间修复玩家25、存活僚机35、母舰180，均封顶、不复活死亡友机。
- 8座炮塔自动扫描、水平转向，炮管独立俯仰；底座保持水平。炮口闪光、加粗炮弹、低频合成炮声。
- 炮塔0.25秒交错扫描一次；实体弹速580m/s、寿命2.4秒、伤害12、射击间隔2.6秒。先判断舰体遮挡与射界，再从真实炮口求匀速截击解，弹体按原连续碰撞实际造成伤害。全场弹体上限仍为192，保持友军免伤。
- 游戏使用不含静态炮头的母舰工厂，加上独立活动炮头，避免重复模型；模型档案与现有GLB仍保留完整静态展示模型，未更换已导出的GLB。
- HUD四个僚机行、五波/46击毁、母舰百分比按配置更新。使用指南、范围和恢复入口同步更新。

## D04测试基线更新说明

五波及更长间隔改变了配置相关的种子摘要。原D04模拟器还会在玩家空放、空波间隔期间随机制造受击，导致其“完整战役获胜”用例因额外两个长空窗而死亡；现在随机受击仅在combat阶段生成，强制死亡/终态测试照常保留。未改纯mission/combat模块、未删断言或跳过失败用例。种子1现为2664步、摘要84e96e70（旧e67c7fa0）；重复确定性、多种子差异、完整五波和100次重开测试均通过。

## 交付边界

本轮基于用户“帧率没问题”的实机反馈，但增加飞机后的目标硬件帧率仍需要再玩确认。Chrome155/SwiftShader用于截图，不作GPU性能结论。玩家没有获得无敌，碰撞仍扣24生命，反复撞舰仍可能失败；需要重玩新的版本确认用户原黑屏是否消失。未验证新的真人难度、多浏览器、驱动差异。构建仍有共享Three.js代码块大于500kB提示。

DSH无新READY任务。可以直接双击仓库根start-play.cmd使用最新dist；旧试玩目录不会自动更新。代码与报告均在本仓库，未上传。
