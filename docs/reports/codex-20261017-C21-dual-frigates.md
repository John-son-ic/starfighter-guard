# C21 — 双舰突袭

2026-10-17。承接额度中断前的改动，已完成集成和验证。三波防守不变，之后两艘慷慨级同时入场，分别在(-650,0,-5000)与(650,0,-5250)。各自有360生命发生器、1800生命舰桥及6门150生命炮塔，独立护盾/碰撞/毁灭状态。两艘舰桥均被毁才胜利；玩家或母舰阵亡优先判负。

每艘破盾仅触发一次：机库门打开后，1架Y翼及2架ARC-170间隔1.5秒出击，共2架Y翼和4架新护航机。Y翼320生命（原260），全部ARC-170为120（原180），玩家仍100。Y翼优先攻击对应敌舰，完成后转攻其他已破盾敌舰；护航机跟随对应轰炸机并迎敌。

每艘存活敌舰每22秒补最多2架秃鹫，总敌机上限仍10；单舰被毁立即停止自身炮塔/后续增援。共和国主炮分配攻击两舰，一艘被毁后集中攻击剩余舰。两舰共4门主炮，单门30伤害/6秒（原单舰2门40/5秒）；总持续对舰火力增加25%，避免直接翻倍造成母舰过早被毁。近防仍12伤害/2.4秒。活动飞机上限21，实体弹体池192。
