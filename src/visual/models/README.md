# Codex程序化建模源码

此目录已有venator.ts、eta2.ts、arc170.ts、vulture.ts；从index.ts的MODEL_CATALOG读取工厂与元数据。

2026-10-16：venator.ts调用venator-detail.ts生成细化版狩猎者级，19,048三角面、9材质批次。新增甲板/机库门分段、舷侧设备、舰桥窗带、炮塔套环、八引擎与腹面结构。GLB仍是按材质合并的静态网格；要修改单个零件，请改程序化源文件后重新导出。它是游戏用近似模型，不是可直接打印的封闭实体或电影原版资产。

同日C06以用户参考图继续更新，以上C05参数保留作历史。现为94,744三角面/9批次/5,557,332字节。venator-geometry.ts提供凸截面放样、倒角块与连接杆；venator-raycast.ts给工厂生成的静态网格建立BVH，仍检测原始三角形，不改变world接口。该索引只供当前静态单材质、正面材质网格使用；工厂合并后建立，修改网格顶点后需重建。GLB不保存JavaScript索引函数，重新导入做游戏碰撞时需自行重建；当前游戏使用工厂，因此已启用。顶点颜色保存细微面板色差与磨损，无纹理文件依赖；材质的shader没有专用补丁。索引合并和8位顶点色降低GLB体积。模型预览开启自阴影，游戏仍使用原有照明，不把预览效果写成游戏性能结论。

工厂约定：createXxxModel(): THREE.Group，模型包围盒原点居中、Y向上、机头-Z、单位米、根节点scale=1。返回纯视觉对象；不包含AI/伤害/游戏循环。各次工厂调用拥有独立资源，使用disposeModel(root)清理；若未来自行clone对象，需另外明确共享资源生命周期。

使用docs/MVP.md的四种轮廓要求。所有模型由Codex通过实际截图检查，不由DSH自行验收。

primitives.ts用挤压轮廓、楔形、低段数球/柱等生成几何，finalize按材质合并成6—7个网格批次，再统一居中并校准长度。无纹理、无骨骼。建模时只统一校准长度，不宣称所有尺寸精确符合正史。

执行npm run models:export可更新public/models下的GLB。运行时可选工厂直接生成或GLTFLoader加载GLB，不要同时实例化两份。C02会另做简化碰撞形状，不应用完整视觉网格逐三角计算所有AI避障。
